# About :open_file_folder:
This github repository is a school project made by three beginning software developers from the school Alfa-College trying to make a simple Jarvis-like A.I. in python. This is our first big programming group project and has a time period of around a month. Our goal is to make an A.I. that can accomplish simple tasks such as telling you what day it is, telling jokes, bringing you to specific websites and more.
